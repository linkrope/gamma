# Domain Docs

This is a single-context repository.

Before exploring a domain area, read the relevant root `GLOSSARY.md` and any
relevant decisions in `docs/adr/`, when they exist. If neither exists,
proceed without comment.

Use glossary terms in issue titles, proposals, test names, and other
domain-facing output. If a planned change conflicts with an ADR, state the
conflict explicitly rather than silently overriding it.
